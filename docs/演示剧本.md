## 故障速查

| 症状 | 处理 |
|---|---|
| 端口被占 | `bash fn_work/start.sh --port 8080` |
| 浏览器没弹出 | 手动开 http://127.0.0.1:8000/（或加 `--no-browser`） |
| 依赖缺 | `fn_work/.venv/bin/pip install -r fn_work/requirements.txt` |
| 想重演干净数据 | 删 `fn_work/runs/` 后重跑（runs 是运行产物目录） |
