## 一、现实基线：原文档承诺 vs 实际设备

| 原文档核心依赖 | 实际状态 | 一期处置 |
|---|---|---|
| 1433D 射频信号源（1MHz–20GHz） | 无 | **B210 TX 替代**：70MHz–6GHz，覆盖 2.4G 全频段与 5.8G ISM（5725–5829MHz < 6GHz）✓ |
| RSA513A 实时频谱仪（≥13.6GHz） | 无 | B210 第二接收通道作监测/自校准（56MHz 实时带宽） |
| EMI 测试接收机（1kHz–3GHz）+LISN | 无 | 一期砍（范围外）。注意：B210 **不构成** CISPR 16-1-1 意义上的 EMI 测量接收机，报告须明示仪器局限 |
| 高频混频器（13GHz 扩展） | 无 | 远期（仪表到位后另立需求） |
| 程控衰减器阵列（≥60dB） | 仅手调 30dB 衰减器×1 | 软件增益步进（细档）+ 衰减器接入/旁路（粗档）替代 |
| 恒温晶振时钟同步 | B210 板载 GPS，支持外接 10MHz/PPS | 单主控机统一软件时间戳，无需外同步 |
| USRP N/X 系列 | **USRP B210（K7 优化版）×1** | 主角；双通道=注入 TX + 监测 RX |

结论：一期台架 = **B210 双通道 + 手调衰减器 + 自建双链路（ESP32 WiFi / NRF24L01）+ Arch 主控机**，全部为现有件。原文档的仪表指标（1MHz–10GHz 生成、13GHz 分析、-150dBm/Hz 底噪等）整体移入"仪表到位后的远期扩展"（§5.5），一期不承诺、不预写数字。

## 二、平台定位锚（方案为什么站得住）

1. **强制国标协议直接照搬**：GB 42590-2023《民用无人驾驶航空器系统 安全要求》（2024-06-01 实施，现行强制性国标）**§5.11 数据链保护**规定了测评协议——干扰样式为噪声/单音/多音，干扰带宽≥链路带宽，**干扰电平自被测链路发射功率 −5dB 起、5dB 步进递增至链路失效，记录失效电平**，限定实验室受控环境实施。【标准原文，openstd.samr.gov.cn；全文 PDF 见引用清单】
   → 平台叙事钉死为："面向 GB 42590-2023 §5.11 的**实验室方法学研究与传导等效实现**"——不是自造协议，而是给国标测法做一个低成本、可复现的本科生实验室实现。注意：标准限定资质机构实施，作品定位为方法学预研/摸底，报告须注明。
2. **ETSI 认可传导等效**：EN 300 328 V2.2.2（2.4GHz 宽带设备）注 4 明确**传导测量允许（按天线增益修正）**；抗阻塞判据 PER/FER≤10%（条款 4.3.1.12）；适应性测试的干扰信号规范（附录 B.7）：带限噪声、100% 占空比、99% 功率带宽为被测占用带宽的 120–200%、平坦度≤4dB。EN 301 893（5GHz RLAN）同框架，另含 RRM 信道搬移时间维度（Table D.1：10s/30min）。→ 我们没有电波暗室不是缺陷，ETSI 口径本来就认台架传导。【ETSI 官方 PDF】
3. **频段合法性内生**：工信部无〔2023〕252 号《民用无人驾驶航空器无线电管理暂行办法》第四条将无人机直连通信限定于 1430–1444 / 2400–2476 / 5725–5829 MHz——我们的自建链路与干扰注入全部落在无人机法定频段的 2.4G/5.8G 定义内，实验主题与频段使用自洽。【官方（福建工信厅转载全文）】
4. **合规红线清晰**（详见 §六）：《无人驾驶航空器飞行管理暂行条例》第 43 条禁止非法拥有/使用反制设备——本平台与"反制/黑飞对抗"严格切割，是被测对象自有的**受控测评**。

```
┌────────────────────────────────────────────────────────────┐
│ L6 报告与演示：scenario → 一键执行 → 三元曲线+失效电平表+报告 │
├────────────────────────────────────────────────────────────┤
│ L5 数据与 AI：SigMF 真值归档 · 谱图CNN干扰识别 · 分组CV评测    │
│              （训练：/toolbox → 4070 远程算力）               │
├────────────────────────────────────────────────────────────┤
│ L4 跨层测量：DUT-KPI（串口） ∥ B210-CH2 监测谱 ∥ 注入事件      │
│              统一主机时间戳 → CSV/JSONL                      │
├────────────────────────────────────────────────────────────┤
│ L3 被测双链路：ESP32 WiFi（PER/重传/RSSI） ∥ NRF24（丢包计数） │
├────────────────────────────────────────────────────────────┤
│ L2 信道与功率：30dB 粗档 ∥ 软件增益细档 · 固定几何近场耦合      │
│              · JSR 标定表（发射端标定+监测通道回校）           │
├────────────────────────────────────────────────────────────┤
│ L1 干扰生成：GNU Radio 3.10 + UHD → B210 CH1 TX              │
│              六类样式（单音/扫频/chirp/带限噪声/部分频带/脉冲） │
└────────────────────────────────────────────────────────────┘
```

关键架构决策：
- **单主控机**（Arch 笔记本）同时挂 B210（USB3）+ ESP32（USB 串口）+ NRF24（USB 转串口/LattePanda），时间对齐退化为软件问题（主机单调时钟），不需要硬件同步。
- **B210 双通道分工**：CH1=干扰注入 TX；CH2=独立天线监测实际注入谱（自校 JSR、验带限噪声平坦度）。须防 TX 直漏进 RX：几何隔离+固定耦合布局一次标定扣除【待实测】。
- **台架形态**：金属屏蔽盒内近场耦合（B210 TX 天线与被测链路天线固定几何）为主，辐射功率 ≤0dBm 量级；此为 EN 300 328 注 4 精神的"天线口传导等效"。开放空间辐射一律不做（§六红线）。

### 4.2 分类学与危害锚点（写报告/答辩直接引用）

- **干扰样式分类学**：Pirayesh & Zeng《Jamming Attacks on Wireless Networks》(IEEE Communications Surveys & Tutorials, 2022，开放 PDF)——常规（全带/部分频带）/跟随式 reactive（时序约束 <1 OFDM 符号 4μs）/欺骗式/脉冲（危害随占空比升）/扫频（约 10μs 换频）；可引用实测锚点：Wi-Fi 18Mbps 宽带 SJR<4dB 即 100% 丢包、312.5kHz 部分频带 SJR<−19dB 失效、2.4G 扫频使吞吐降>65%。
- **传导功率校准流程**：u-blox 白皮书 DWP0013（GNSS 抗扰测评）：传导连接+已知线损+功率校准，C/N0 下降>1dB 判失效、失锁/重捕获时间为指标——对非 GNSS 链路类比"RSSI/SINR 下降 X dB 判失效"。【厂商白皮书】
- **GNSS 前车之鉴**：市售非法干扰器多为 CHIRP 锯齿扫频 1565–1585MHz 约 10W——反面印证 chirp 样式在样式矩阵中的必要性。

### 4.3 三个方向判断（创新性价比）

1. **最高：受控干扰注入 + 干扰样式识别**。公开数据集普遍缺受控 JSR/干扰类型真值标注，而"B210+衰减器+屏蔽盒"恰是本科生实验室独有能力——**自建受控干扰 SigMF 真值数据集本身就是可发表/可答辩的差异化贡献**；模型侧复现双流/谱图分类即可成立。
2. **次高：RFF 指纹识别+蒸馏边缘部署**（4070 训练→Jetson 部署，参数量/时延/功耗实测数字齐全，故事完整）；须公开集+自采双验证，且必须分组 CV（2607.01025 教训）。
3. **最低：纯仿真 RL 抗干扰**。2024–2026 论文密集且多为纯仿真，评委易质疑；仅当做成"ESP32 跳频链路+B210 实干扰"硬件在环小闭环时才值得投入。

### 5.4 关键工程细节与坑（提前写进设计）

- **B210 自漏**：CH1 发射会经空间/盒内耦合进 CH2 监测天线——固定几何一次标定扣除；监测天线加指向/距离隔离【待实测】。
- **56MHz 实时带宽边界**：2.4G 整段（83.5MHz）超一点，带限噪声须按 ≤56MHz 设计或分段；5.8G 只做单信道段监测。
- **NRF24 无 RSSI**：链路质量用 RPD（1bit 门限）+ARC_CNT/PLOS_CNT 计数，指标口径写"丢包/重传"不写"信号强度"。
- **ESP32 丢包统计**：esp_wifi 无专用 API，用 UDP 定长流上层计数（我们自己的流，可控）。
- **功率域**：B210 最大输出约 +10dBm 量级【待实测】，加 30dB 衰减器后远低于 ISM 限值（2.4G EIRP≤100mW / 5.8G≤2W），合规余量大；步进精度取决于软件增益档【待实测标定】。
- **5.8G 被测缺位**：ESP32/NRF24 均为 2.4G 器件——一期被测=2.4G 双链路；5.8G 仅验证注入+监测能力（频段合法且在 B210 覆盖内），被测链路留给远期硬件。

### 5.5 远期扩展（仪表到位后，呼应原文档）

雏形立住后向导师申报重型仪表的顺序建议：①程控衰减器/步进衰减（自动化粗档，R9 接口已预留）→ ②射频信号源（波形保真度与频率准确度升级，PyVISA/SCPI 接入）→ ③实时频谱仪（DPX 级监测与跳频分析）→ ④EMI 接收机+LISN（EMC 摸底，进入 CISPR 16 口径）→ ⑤混频器 13GHz 扩展。R9 抽象层保证 scenario 体系不用重写。

## 七、与《安航云盾》的借力点（已获负责人确认可互补）

1. **平台→云盾**：R10 预研把实测"PER–功率台阶"映射为 ArduPilot SITL 的链路丢包/时延注入——为云盾"通信链路风险通道"（其计划书 §4.1 链路健康度）提供**可复现的受控数据源**；M1 三元曲线可直接作云盾计划书 §7 测试验证的实证素材。
2. **云盾→平台**：低空安全应用叙事（平台从"设备"升格为"低空经济安全链路的测评基础设施"）；可借的 Jetson Orin NX 共用（二期 RFF 边缘部署，§4.3 判断 2）。
3. **边界**：两个战役目录、两套 JOURNAL 独立记账；借用关系在双方文档互链留痕，设备借用经各自导师渠道。

## 八、同类作品与差异化

- **先例（评委认可过）**：南航"空中反'黑'卫士——无人机频谱认知仪"获中国国际大学生创新大赛第六届（2020）金奖，获国家无线电监测中心应用【权威媒体（中国教育在线江苏站）】；"无人机智能频谱监测仪"（南航）见第四届复活赛名单【官方（cy.ncss.cn）】→ 无人机+频谱主题在创新大赛有金奖血统。
- **空白**：2024–2026 电赛未见"无人机+电磁抗扰"公开赛题（2024 C 题无线传输信号模拟为近邻）【官方赛题页】；挑战杯相邻主题为"拒止环境集群搜索"（2025 揭榜挂帅）与"低空目标识别"【校方官方】。
- **我们差异化三件**：①**受控 JSR/样式真值标注的 SigMF 数据集**（公开集普遍缺失，实验室独有能力）；②**国标 GB 42590 §5.11 协议自动化**（对齐强制国标的合规话术）；③**AI 识别+一键报告闭环**（从注入到识别到报告一条命令）。

## 九、风险与对策

| 风险 | 对策 |
|---|---|
| B210 TX 自漏进监测通道 | 固定几何标定扣除+隔离；真值以发射端标定为准【待实测】 |
