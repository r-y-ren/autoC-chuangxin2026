# 一期功能对照清单：原文档承诺 vs 已实施（2026-10-06 定稿）

> 对照基准：docs/无人机通信链路电磁干扰测试平台.md（2026-09-20 团队稿）三大研究内容与量化指标；
> 实施基准：fn_docs/responsibility.md（34 函数）+ fn_work 实测（86 测试绿、audit-v2 审计 2026-10-06）。
> 分类：✅ 已实施 / 🟡 妥协（口径变化但目标达成） / ❌ 未实现（砍掉或待硬件） / ➕ 超出原文档的新能力。

## 二、🟡 妥协（目标达成但口径改变——原因均为"现有设备优先"决策）

| 原承诺 | 一期现状 | 妥协原因/替代物 | 恢复路径 |
|---|---|---|---|
| 1MHz–10GHz 干扰生成（1433D 信号源） | **2.4GHz ISM 单频段**（B210 实际 70MHz–6GHz 能力，合规约束在 2400–2483.5MHz） | 无信号源，B210 替代+合规收窄 | 仪表到位后经 create_instrument_backend（pyvisa 槽）扩展 |
| 程控衰减器阵列 ≥60dB | 30dB 手调衰减器（粗档）+ B210 软件增益（细档） | 无程控衰减器 | 申报仪表后接入 |
| 误码率 BER（N_error/N_total） | **PER 丢包率+相对吞吐（1-PER）** | 自建链路为包级统计（白盒），比特级 BER 需解调链路 | 真机后可加原始比特流比对 |
| 吞吐量波动 | 相对吞吐（1-PER 曲线） | 无真实业务流 | iperf 类业务流可后加 |
| 跨仪器时间戳同步（频谱仪×USRP） | 单主机单调钟对齐（≤50ms 目标） | 无独立频谱仪，单机三路同源 | 多仪表后可升级 |
| 空间损耗/动态衰落模拟（对数距离模型 L(d)） | 功率台阶等效（距离→损耗由步进覆盖） | 未建 n/Xσ 衰落模型 | 可加信道模型模块（Sionna 槽位） |
| 高精度频率（<1ppm） | 未强制（B210 TCXO 约 2ppm 级；GPS/PPS 接口在板未启用） | 无 GPSDO 驯服 | B210 板载 GPS+PPS 可启用 |
| 全链路频响补偿矩阵（L_link(f)+C_ant(f)） | 发射端增益标定表（单频点） | 无频谱仪逐频点标定、无天线系数 | 仪表到位后扩展 calibrate_power |
| 13GHz 高频扩展（混频器） | ❌ 未做 | 无混频器 | 远期 |
| 协议级深度分析（私有协议解调重构、跳频机制剖析） | 白盒自建链路的链路层指标替代 | 真机私有协议不可解析（范围外） | 不打算恢复（合规+黑盒现实） |
| 数据集/识别模型真实数据 | 合成数据全流程（真机数据待采） | 硬件未到 | P6 真机激活轮 |
