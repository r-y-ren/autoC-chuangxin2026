# 无人机链路抗干扰测评台（STITP 课题一期）

> 面向队友的零术语说明。出处与技术细节见 requirements.md 与《../docs/前沿技术与实现方案补充.md》。

## 这个东西是干什么的

我们自己搭两条小型无线链路（一块 ESP32 跑 WiFi、一块 NRF24 跑数传），当作"无人机通信链路"的替身。用一台软件无线电设备（USRP B210）按设定好的方式朝它们发干扰，全程记录链路表现变差的过程，最后自动出报告：什么样的干扰、多强、链路坏到什么程度、机器认不认得。

一句话：一台可重复、可量化、鼠标点点就能操作、**以后买到新设备能像插积木一样直接加装**的无人机链路抗干扰测试机。

## 工作流程（从开机到报告，演示全程不碰命令行）

1. **准备**：ESP32 和 NRF24 用 USB 线接到主机；B210 接 USB3；天线按固定位置摆进金属屏蔽盒。
2. **打开操控台**：双击启动（或一条命令），浏览器自动打开操控台——之后全程只用鼠标。
3. **选场景**：点一张场景卡片（比如"国标·噪声干扰"），或自己拖滑杆调：干扰样式、起始功率、每档加多少、每档多久。
4. **开始测试**：点"开始"。仪表盘实时显示链路丢包/速度/延迟曲线跟着干扰往下掉。
5. **自动出报告**：跑完在报告中心点开结果——三张曲线、失效电平表、AI 识别结论，一键导出；历史结果可对比。
6. **急停大按钮**：任何时候点红色急停干扰立即停；设备掉线也会自动急停。

## 项目功能（一期承诺）

- **六种干扰样式**：单音、扫频、啁啾、带限噪声、部分频带、脉冲——覆盖国标 GB 42590-2023 §5.11 的"噪声/单音/多音"及其扩展。
- **两条被测链路**：ESP32 WiFi + NRF24 数传，各带丢包/信号统计上报；没插硬件时可用"合成数据演示模式"全程演示。
- **国标步进测法**：功率从被测链路发射功率 -5dB 起步、每 5dB 一档加到链路失效，自动记下失效电平（国标原文口径）。
- **模块化加装（硬承诺）**：干扰仪表、被测链路、干扰样式三类东西都是"插槽"——以后买到信号源/频谱仪，写一个新插件接上就能用；**不许推倒重来**。
- **Web 操控台**：驾驶舱操控（样式选卡/功率滑杆/急停）+ 实时曲线仪表盘 + 场景卡片一键测 + 报告中心；浏览器打开就用，演示零代码。
- **示意动画（锦上添花）**：链路光带变色、干扰波纹等动画跟随真实数据动——功能完整性优先，动画不作为验收硬项。
- **全程留痕**：所有射频录制按 SigMF 开放格式存档，带真值标签，可复现、可对外发布。
- **AI 认干扰**：谱图分类模型认出六种干扰+无干扰；训练用 4070 笔记本远程算力。

## 什么算成功（五条）

1. 一条命令/一次点击跑通"注入→测量→报告"闭环；
2. 带真值标注的受控干扰数据集落盘；
3. AI 能分清六种干扰+无干扰（准确率如实报告，不设数字门槛）；
4. 所有数字当场可复现，报告里每个数都能溯源到原始数据；
5. 换新设备=加插件，现有场景和流程零改动。

## 本轮新增（演进一，软件收尾）

- **双击就能开**：start.sh / start.bat——起服务、自动弹浏览器，不用敲命令；
- **报告中心**：操控台里点开任意一次历史测试，图文报告直接看、可导出；
- **图表全中文**：内置开源中文字体，曲线图/混淆矩阵不再有方框；
- **快跑不掺水**：加速倍速下"持续多久算失效"的判据同步缩放，快速演示也能出真实口径的失效电平，报告自动标注加速倍率；
- **标定与断点**：有标定表就自动换算功率；测试中断了从断点续跑，不从头来；
- **中期材料一键汇编**：一条命令把最新实测（失效电平/曲线/识别成绩）汇成材料初稿，数字全部可溯源。

**等硬件到货**（插上即用，不用改软件）：真无人机电台的串口接入、B210 真发射、4070 真训练——三类插槽都已就位。

## 演进轮二新增（界面与设备状态）

- **设备状态一目了然**：页面顶部常驻状态条——B210、ESP32 串口、NRF24、依赖、算力、供电这些电子件机器自动探测亮灯（绿=就绪/红=缺/黄=待办）；屏蔽箱、天线几何这类机器测不了的，给你勾选"已确认"。缺件时红徽标提示，一眼看出差什么、该买什么。
- **界面精修**：全部页面统一深色驾驶舱风格（卡片/按钮/配色/间距全套规整），急停键红得醒目，报告表格清晰可读。

## 演进轮三新增（数据活起来 + 交互）

- **数据真流上屏**：点"开始"后，丢包/信号曲线跟着真实计算的数据滚动（不是假动画——就是后台算的那套合成数据，以后接真机同一根管子直接换源）；
- **实时双曲线**：丢包率和相对吞吐两条线边跑边画，鼠标停上去看数值；
- **运行进度卡**："第几步/共几步、当前干扰功率、已用时间"实时刷新；
- **事件时间线**：注入、断链、断连一个个事件流式弹出，新的高亮提醒；
- **拖滑杆先预览**：测试前拖功率滑杆，立刻看到"这个强度下链路大概掉多少"——预览曲线和实测用的是同一个响应模型，拖满意再开测。

## 演进轮四新增（结果仪表盘）

- **首页一眼看成果**：改成仪表盘网格——最新测试结果卡（失效电平/样本数/曲线缩略图）、历史测试与两两对比、识别模型与数据集指标、平台能力总览（样式库/场景卡/插件槽/累计测试数）；
- **首次打开自动备货**：没有历史数据时，页面后台自动跑一轮演示测试（几秒钟），跑完四张卡自动填满——所有数字都是真跑出来的，点进报告中心能对上号；
- **诚实角标**：合成数据卡片统一标"合成数据"，绝不冒充实测。
