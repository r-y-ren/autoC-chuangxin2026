## 三问直答

1. **功能是否完善？** 合成链路维度完善：27/27 函数 wired、70 单测绿、fn-check 三项 PASS、demo 一条命令三件产出（报告+失效电平 5.0dB+识别样例）、分组 CV Macro-F1=1.000（可分合成集，只记录不设门）。真实世界维度**按设计未激活**（B210/串口/PyVISA/pymavlink/4070 均惰性占位）；已知功能缺口：断点续跑、标定表消费、加速因子与判据耦合（见 P3）、操控台报告页入口。
2. **要补充什么？** 见提案 P1–P6（每条已登记 registry.jsonl）。
3. **作为产品是否完整？** 对"演示级"目标约 **7.5 成**：有可用操控台+急停+WS+一键演示；缺一键启动器（双击→浏览器）、报告中心页面渲染（端点在/页面无入口）、产品内快速上手文档；另有**图表中文字形缺失**（matplotlib DejaVu 无 CJK，三图中文标签渲染为方框——中期材料质量硬伤）。

## 提案（发散≥3 含激进项；分流标注）

### P1 硬件就位准备包 [高]
- 现象：blueprint hw-fw 验收命令无固件工程可跑；真串口路径仅单测覆盖。
- 假设：R3 固件属硬件角色未落（职责在 contracts/sw-hw-interface.md，不在 fn 树）。
- 改进方向：esp32_link/nrf24_link 实装+烧录 SOP+串口联调自测脚本。
- 预期信号：hw-fw 命令编译过；真机串口 JSON 行被 parse_serial_line 消化（5 分钟本底）。
- 分流：战役硬件任务包（非 fn 树）。

### P2 产品最后一公里 [高]
- 现象：man-ui-demo 判据依赖零代码全流程，但无双击启动器、报告页无入口、三图中文方框。
- 假设：R10/R8 页面与出口职责部分悬空；图表字形属 plot_triple_curves/train_classifier 的渲染资源缺口。
- 改进方向：start 启动器（起服务+开浏览器）+操控台报告中心页+快速上手 README+中文字体打包（或标签英文化）。
- 预期信号：零代码走查单一次通过；三图无缺字告警。
- 分流：参数/逻辑级（UI 内改造）+渲染资源项。

### P3 加速因子与判据解耦 [中]
- 现象：gb42590@SPEED=40 → 0/10 失效；demo 卡（sustain 0.04s）→ 5.0dB 失效——同一链路因 sustain/步窗耦合而口径漂移。
- 假设：execute_scenario/check_failure 职责正确，LINKBENCH_SPEED 只缩步长不缩 sustain 属实现语义缺口。
- 改进方向：速度因子同步缩放 sustain/disconnect（或文档钉死"加速=演示专用，判词语义仅 1.0"）。
- 预期信号：任一速度下国标卡都能报失效电平，或限制条款入 README/报告脚注。
- 分流：参数/逻辑级（[改造] execute_scenario）。

### P4 标定消费+断点续跑 [中]
- 现象：fn-implement 评审遗留两项裁决（executor 未消费 calibration.json；断点续跑未实现）。
- 假设：责任文档签名意图明载"断点 run 目录"与"内部取标定表"。
- 改进方向：executor 读标定表换算功率档；run 目录进度续跑。
- 预期信号：删半重跑从断点续；标定表条目出现在 report。
- 分流：参数/逻辑级偏结构（回 fn-divide 快速通道确认）。

### P5 中期材料线 [中]
- 现象：blueprint doc-mid/doc-final 验收命令（docs/build.py --mid/--final）无实现；metrics 键清单已冻结无消费方。
- 假设：document 角色里程碑未开工（m2 硬节点 12 月）。
- 改进方向：build.py 编译入口+中期报告模板（数字仅引 metrics.json）。
- 预期信号：build.py --mid 产出可读材料稿。
- 分流：战役 document 任务包（非 fn 树）。

### P6 真机全链路激活轮 [激进]
- 现象：全部真机路径为惰性占位，metrics.json 为空——合成 F1=1.000 无真实信息量。
- 假设：证据强度轴——当前一切结论止于 mock 证据级；STITP 中期需要至少一轮真机实测证据。
- 改进方向：B210 真发射+真串口双链路+toolbox 4070 真训练各打通一次，产第一份真机 metrics；附 SigMF 数据集发布包（LICENSE+说明）作省级门槛资产。
- 预期信号：metrics.json 出现真机键值；数据集可对外发布。
- 分流：战役硬件+软件混合任务包（结构性，回 fn-divide/战役蓝图层）。
