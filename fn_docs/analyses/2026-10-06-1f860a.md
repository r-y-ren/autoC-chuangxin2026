## 四、本轮新提案（≥3 含激进项）

### P7 sw-ai 容错与数据集路径收口 [高·轻量]
- 现象：sw-ai rc=1——runs/dataset_v1 缺失时 index_dataset 写索引抛 FileNotFoundError（audit-v2 步 6）。
- 假设：index_dataset 的职责是"扫描 runs 校验+索引"，目录缺失应给可操作报错或空索引，不应裸异常；eval 入口默认路径应指向实际数据集（demo gen）。
- 改进方向：目录缺失→友好报错/自动就近数据集；补默认路径。
- 预期信号：sw-ai 在无数据集时 rc=2 且提示"无数据集，先跑 demo 或 gen"；有数据集时 rc=0。
- 分流：参数/逻辑级（[改造] index_dataset/eval 入口）。

### P8 最小硬件 BOM 执行+固件先行 [高]
- 现象：hw-fw 验收命令悬空（build_all.py 不存在）；BOM 待购两件。
- 假设：固件代码属 P1 提案但不依赖板子在手——可先建 esp32_link/nrf24_link 工程+build_all.py（编译过=骨架绿），到货即烧。
- 改进方向：固件工程落位（串口 JSON 契约实现）+按 BOM 采购；到货后联调。
- 预期信号：装 pio 机器上 hw-fw 编译过；真串口 5 分钟本底曲线。
- 分流：结构性（演进轮二，硬件任务包；BOM 采购=用户动作项）。

### P9 零代码走查一次走完+截图入档 [高·人工协同]
- 现象：man-ui-demo 判据（开浏览器→跑卡→点开历史报告→全程鼠标）未走；doc 报告缺 UI 配图。
- 假设：页面已就绪（评审 A5 过），缺的是走查证据。
- 改进方向：按剧本走一遍，截 ui-*.png 入 run figs（sw-doc 契约路径）。
- 预期信号：走查记录入档；P2 可判 achieved；材料稿配图就位。
- 分流：人工项（不涉代码）。

### P10 合成数据先行软著+数据集发布包 [激进]
- 现象：软著×2 与数据集发布（省级结题门槛）排在真机后，但工具链已能产可发布件。
- 假设：软著材料（软件源代码+说明书）不依赖真机；数据集发布包（LICENSE+SigMF 说明+合成真机混排策略）可先立骨架，真机数据后补替换。
- 改进方向：以现有 86 测绿代码出软著申请件初稿+数据集发布包骨架。
- 预期信号：软著材料初稿与数据集包（含 LICENSE）落 docs/ 或独立发布目录。
- 分流：战役 document 任务包（可与 P5 材料线同波）。
